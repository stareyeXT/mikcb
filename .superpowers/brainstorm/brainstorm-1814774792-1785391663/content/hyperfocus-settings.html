与 Live Updates 的差异

HyperFocusApi 方案设置项更精简，聚焦于超级岛显示层面的自定义：

保留项

  • 提醒时机（三阶段开关 + 提前时间）
  • 课名 / 地点 / 倒计时 显示开关
  • 自定义标签文字和颜色

移除项

  • 保活相关设置（不适用）
  • 状态栏岛精细自定义
  • 展开态岛逐字段模板
  • 通知栏相关选项

毛坯版只实现「测试」功能（发一条硬编码通知），其余页面先做 UI 占位。
